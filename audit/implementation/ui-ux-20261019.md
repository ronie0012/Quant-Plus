# UI/UX integration checkpoint — 2026-10-19

## Goal and boundaries

Make the public site and personal paper workspace easier to navigate, read and use on desktop and phones, with coherent learning, research, planning and review journeys. Preserve the existing brand, stack, local data and previous intelligence repairs. This is local application work, not a deployment, backend migration or live-provider certification.

## Implemented flows

- Five primary areas remain Home, Discover, Portfolio, Review and More. Learn & practise has a secondary entry; contextual navigation groups related tools without adding a sixth primary area.
- The mobile workspace drawer traps focus, closes with Escape, restores focus and resets when resized to desktop. The public menu has equivalent keyboard and resize handling.
- Home prioritises next actions and separates its saved custom layout from the default overview. Optional learning comes before wallet funding in first-session guidance.
- More is a searchable task-grouped catalog with purpose descriptions and unavailable-capability labels.
- Watchlist additions require a company choice and confirmation. A failed save preserves the choice for retry.
- Basket starts empty, requires company selection and an estimate check, and invalidates that check when edited. Stable UI row identities preserve input focus while settlement intent IDs still change on edits.
- Review separates decision plans, overview and execution review; switching views preserves an unfinished plan. Stock-specific plan links retain their context.
- Ripple leads with events and affected companies, then an explanation and research/watchlist/plan actions. Graphs, historical validation and saved grading are supplementary. News and hypothetical scenarios remain distinct.
- Stock workspaces proceed through price action, research/evidence and a decision canvas; depth, statistics and the paper ticket remain available through disclosures.
- Learn recommends a next step. Investor DNA separates capacity and tolerance, groups questions, retains drafts after failed saves and supports cancellation. The welcome flow is optional and recoverable without funding. Company practice resumes and protects restart; Tutor starts with concept checks and makes AI help optional.
- Public pages share an honest paper-terminal entry, clear learning access and restrained descriptions of provider/AI limitations.
- Shared cards, captions, wrapping, touch targets, primary-action contrast and mobile card-header spacing were improved. Research-result tables are keyboard-scrollable.
- Authentication preserves safe workspace return destinations and rejects external/non-workspace locations.
